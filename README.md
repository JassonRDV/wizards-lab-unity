# Wizard's Lab — Unity 3D Scene

A stylized wizard laboratory scene built in Unity with the Universal Render Pipeline. The project focuses on environment presentation through 3D assets, materials, lighting, animation assets, and particle effects.

## Preview

![Wizard's Lab scene preview](gif/magic.gif)

## Included assets

- A laboratory environment with a cauldron, shelves, bottles, books, and candles.
- A wizard character model and idle/walk Animator Controller assets.
- Environment and character textures and materials.
- Particle prefabs for the staff and cauldron.
- A Shader Graph asset for glow effects.
- A scene configured with multiple lights and URP rendering settings.

## Technology

- Unity **6000.0.17f1**
- Universal Render Pipeline **17.0.3**
- Shader Graph, Particle System, and Animator assets

## Open the project

1. Clone this repository.
2. In Unity Hub, add the repository's root folder as an existing project.
3. Open it with Unity 6000.0.17f1 and let Unity import the assets and resolve packages.
4. Open `Assets/Scenes/Wizard's Lab.unity`.
5. Inspect the scene in Scene or Game view, or enter Play mode to preview its setup.

## Scope

The repository contains a visual scene and supporting art assets. There are no C# gameplay scripts in the inspected project tree.
